APACE 的核心思想 为 把“视角选择（yaw）”当成一个优化变量，让无人机主动选择“既安全、又有信息量”的朝向。
src/里的apace_1 可以实现，无人机在去一个指定的目标点时，可根据路上识别到的障碍物自动避障，在避障过程中会自动将机头对准障碍物，来获得更多的特征点

APACE 不是在解决“怎么飞到目标点”  而是在解决：飞行过程中，机头该朝哪里，才能既安全、又有感知价值。

❌ 传统系统的问题：机头跟着速度走，绕障时可能“侧着飞”，相机对着空白区域，头固定面朝前 → 容易正对墙感知直接失效，感知是被动的，看到了就算没看到也无所谓

👉 结果：SLAM 不稳定，深度被遮挡、在狭窄环境里“瞎飞”

APACE Yaw Wrapper（Gazebo + PX4 + D435）
1. 项目简介
本模块在 Gazebo + PX4 SITL 仿真环境中，基于 D435 深度相机 与 位姿信息，实现了一个感知驱动的 yaw 控制与绕障飞行方案。
无人机在飞行过程中可根据场景自动切换航向策略：
直飞阶段（GO）：机头朝向速度/目标方向
近障阶段（ORBIT）：围绕障碍物飞行，机头持续朝向障碍
脱离阶段（ESCAPE）：绕障完成后离开障碍并继续飞向目标点
该方案在不依赖全局地图的情况下，实现了类似 APACE 论文中“绕 box 半圈、机头始终对准 box”的飞行行为。

5. 与 APACE 论文的关系

本实现不是论文中的全优化版本，而是一个工程化近似实现，核心对应关系如下：

论文思想本方案实现
感知驱动的 yaw 调整	基于深度 ROI 的 yaw 触发与切换
机头保持可观测性	绕障阶段 yaw 指向障碍中心
轨迹 + 视角耦合	GO / ORBIT / ESCAPE 状态机
无地图可运行	仅使用深度图 + 位姿
该方案验证了：仅靠局部感知也能实现稳定的“绕障 + 盯障”行为。
